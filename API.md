## Adaptations (generator rules and hand-written code)

- Namespaces: each Go module in a namespace (`kubo`, `boxo`, `ipld`, `multiformats`, `libp2p`, `car` (`github.com/ipld/go-car/v2`), `datastore`, `go`), with a `package:ipfs_ffi/<namespace>.dart` file that exports all of its libraries (`import 'package:ipfs_ffi/kubo.dart' as kubo;`); the per-package libraries stay underneath. The module → namespace table is in `go/gen/namespaces.go`.
- `context` (`package:ipfs_ffi/go/context.dart`, hand-written): `background`, `withCancel`, `withTimeout`, `withDeadline`; `CancelFunc` is callable (`cancel()`).
- `go.readerStream` (`package:ipfs_ffi/go/io_stream.dart`, hand-written): any `io.Reader` handle as a `Stream<Uint8List>`, in 256 KiB pieces; cancel through the reader's context.
- `config.Profiles` (hand-written): `profiles[name]!.transform(cfg)`; in Go it is a map of functions.
- `ipfs dag put`/`ipfs dag get` (`dagPut`/`dagGet` in `package:ipfs_ffi/kubo/core/commands/dag.dart`, hand port in `go/manual_dag.go`): in kubo they are the body of the commands, not a library function; same defaults as the CLI (dag-json → dag-cbor, 2 MiB limit), default hash `sha2-256`.
- `ipfs dag export`/`ipfs dag import` (CAR files; same library as `dagPut`/`dagGet`, hand port in `go/manual_car.go`): `dagExport`/`dagExportFile` (CARv1, `localOnly` = `--local-only`) and `dagImport`/`dagImportFiles` (CARv1/v2, `pinRoots` = `--pin-roots`, returns roots and statistics); they take the `IpfsNode`, like the command. No progress bar nor fast-provide of the whole DAG; the root is announced by the CoreAPI's `Provide`.
- Pubsub: the node needs `node.BuildCfg(extraOpts: {'pubsub': true})` (the daemon's `Pubsub.Enabled`); `sub.next(ctx)` delivers one message at a time (example 08 turns it into a `Stream`).
- A concrete handle that implements an exposed interface extends its class (`merkledag.RawNode`/`ProtoNode` → `Node`), to be accepted where Go accepts the interface; a struct that embeds an interface is a handle, not a DTO.
- A map keyed by a value type (`map[peer.ID][]Multiaddr`) becomes `Map<Id, List<Multiaddr>>`; keyed by an integer (`map[multicodec.Code]uint64`), `Map<int, int>`.
- A struct of exported fields that is an object (`linking.LinkSystem`, `go-datastore.NullDatastore`, table `handleTypes`) is a handle; the handle of a struct returned by value keeps the pointer (it is valid as `T` and `*T`).
- DTO method (`car.Header.hasIndex`, `cid.Prefix.sum`): the receiver goes by value; what the method changes in it does not come back.
- A getters-only interface (snapshot, `blocks.Block`) as a parameter: Dart builds the class (`Block(cid: c, rawData: d)`) and Go receives a struct that returns those values.
- A `chan<- T` channel passed in an option (`options.Unixfs.Events`) becomes a `StreamSink<T>` (`options.unixfs.events(controller.sink)`); the real item type of a `chan<- any` comes from the generator's `chanElem` table (`AddEvent`). Like `ipfs add`, the channel is closed when the call returns: every event arrives and the sink closes before the `Future` completes.
- A package variable becomes a getter; a named function type (`libp2p.RoutingOption`) is an opaque handle, created only in Go; an unnamed func identical to a named type of the package, or of one it imports, uses the named type (`bsfetcher.DefaultPrototypeChooser`).
- A function parameter that returns nothing, `bool` or `error` (a callback) becomes a Dart function (`idx.forEach((mh, offset) {...})`): Go calls a real callback, which takes the arguments to Dart in batches and waits for the verdict; `false` or an exception stops Go, and the call throws the original Dart exception. `batchSize` (optional): invocations per batch, default 1024 (up to 128 KiB, measured) or 1 when the callback receives Go objects; Go stays at most `batchSize - 1` ahead. The call's objects are in use (`isBusy`, `IpfsService.busy`); a call to them from inside the callback that waits on a lock the Go function holds becomes `IpfsDeadlockException` (WIRE.md, "Callback").
- Errors that wrap `io.EOF`, `io.ErrUnexpectedEOF`, `context.Canceled`, `context.DeadlineExceeded` or IPLD's not found become `IpfsEof`, `IpfsUnexpectedEof`, `IpfsCanceled`, `IpfsDeadlineExceeded` and `IpfsNotFound` (subclasses of `IpfsException`), as Go's `errors.Is` would find them.
- A root that is only a struct type (`bsadapter.Adapter`, `basicnode.Prototype__Any`) becomes an empty constructor (`Adapter()`, Go's `new(T)`), and its fields, getters and setters.
- An interface that embeds another gets the cast from it (`idx.asIterableIndex()`, Go's `x.(index.IterableIndex)`).
- A pointer to a basic type (`DagByteRange.To *int64`) becomes `int?`: null is nil.
- A function that returns an unexported type is seen in Dart through an exported interface (table `resultAs`: `merkledag.NewDAGService` → `format.DAGService`); on the wire it is the object's handle.
- A type defined from an interface of another package (`type BaseBlocks blockstore.Blockstore`) gets no methods of its own: list them as roots on the type itself (`node.BaseBlocks.Has`).
- The same Go object always has the same handle, wherever it comes from (a cast, a field read again).
- Methods and functions with a `context.Context` are asynchronous (`Future`); channels become `Stream`; `(T, error)` becomes `T` with `IpfsException`.
- Variadics become an optional `List`; functional options mirror the package variables (`options.unixfs.pin(true, '')`).
- A synchronous `NewX` that returns the handle `X` of the same package becomes `factory X(...)` (not for a DTO: `car.newHeader` is a function).
- An `io.Writer` parameter is a `GoHandle?`: a Go object that implements it (`os.File`, `bytes.Buffer`); null = `io.Discard`.
- `fsrepo.Open`: the host cleans the path (`repoPath`, the form `Repo.Path()` returns) before opening, so the config commands, which reopen the repo by `Path()`, reuse the open repo (`fsrepo` keys the open one by the raw string).
- `uint64` integers travel as the same 64 bits in a Dart `int` (like `Uint64List`): from 2^63 up they read as negative; `BigInt.from(v).toUnsigned(64)` reads them unsigned (each field's doc warns).
- An I/O interface parameter (`io.Reader`, `io.ReaderAt`, `io.ReadSeeker`, `car.SectionReader`...) accepts a `Uint8List` (when a `bytes.Reader` implements it) or a handle that implements it (kubo's `files.File`, `os.open`).
- Value types (CID, path, peer ID, multiaddr) keep the string; validation happens in Go, when they cross.
- `config.Config` keeps kubo's JSON (the same as the repo's `config` file) in `json`.
- A Go `nil` result where Dart expects an object becomes `IpfsException`.
- Kubo runs in `ipfs_host`, in another process (`IpfsService.start()` before the API; protocol in `WIRE.md`): a Go panic stops only the service, and pending calls fail with `IpfsServiceException`.
- Handles are freed by the Dart `Finalizer` (in batches, through the service's Free function) and are only valid in the service they were born in; Go resources (node, repo) still need Go's own `Close`.
