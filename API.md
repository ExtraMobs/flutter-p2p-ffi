## Adaptations (generator rules and hand-written code)

- Paths: each Go package is one library under `lib/go/`, at its path inside its module; the module is named by the last segment of its path without `go-` and the major version, a nested module keeps the outer one's path, and the Go standard library sits beside the modules (`github.com/ipfs/boxo/mfs` → `package:p2p_ffi/go/boxo/mfs.dart`, `github.com/ipfs/go-cid` → `go/cid.dart`, `github.com/ipld/go-car/v2/index` → `go/car/v2/index.dart`, `context` → `go/context.dart`). Each Go type has a single library, the one of its package (the kubo commands' result types too), and no public library re-exports another: the generator refuses an `export` outside `lib/src/`, except in `lib/p2p_ffi.dart`, the entry point of the runtime.
- `context` (`package:p2p_ffi/go/context.dart`, hand-written): `background`, `withCancel`, `withTimeout`, `withDeadline`; `CancelFunc` is callable (`cancel()`).
- `go.readerStream` (`package:p2p_ffi/go/io_stream.dart`, hand-written): any `io.Reader` handle as a `Stream<Uint8List>`, in 256 KiB pieces; cancel through the reader's context.
- `config.Profiles` (hand-written): `profiles[name]!.transform(cfg)`; in Go it is a map of functions.
- `ipfs dag put`/`ipfs dag get` (`dagPut`/`dagGet` in `package:p2p_ffi/go/kubo/core/commands/dag.dart`, with the generated result types of the other `ipfs dag` commands in its `dag.g.dart` part, hand port in `go/manual_dag.go`): in kubo they are the body of the commands, not a library function; same defaults as the CLI (dag-json → dag-cbor, 2 MiB limit), default hash `sha2-256`.
- `ipfs dag export`/`ipfs dag import` (CAR files; same library as `dagPut`/`dagGet`, hand port in `go/manual_car.go`): `dagExport`/`dagExportFile` (CARv1, `localOnly` = `--local-only`) and `dagImport`/`dagImportFiles` (CARv1/v2, `pinRoots` = `--pin-roots`, returns roots and statistics); they take the `IpfsNode`, like the command. No progress bar nor fast-provide of the whole DAG; the root is announced by the CoreAPI's `Provide`.
- Pubsub: the node needs `node.BuildCfg(extraOpts: {'pubsub': true})` (the daemon's `Pubsub.Enabled`); `sub.next(ctx)` delivers one message at a time (example 08 turns it into a `Stream`).
- A concrete handle that implements an exposed interface extends its class (`merkledag.RawNode`/`ProtoNode` → `Node`), to be accepted where Go accepts the interface; a struct that embeds an interface is a handle, not a DTO.
- A map keyed by a value type (`map[peer.ID][]Multiaddr`) becomes `Map<Id, List<Multiaddr>>`; keyed by an integer (`map[multicodec.Code]uint64`), `Map<int, int>`.
- A struct of exported fields that is an object (`linking.LinkSystem`, `go-datastore.NullDatastore`, table `handleTypes`) is a handle; the handle of a struct returned by value keeps the pointer (it is valid as `T` and `*T`).
- DTO method (`car.Header.hasIndex`, `cid.Prefix.sum`): the receiver goes by value; what the method changes in it does not come back.
- A getters-only interface (snapshot, `blocks.Block`) as a parameter: Dart builds the class (`Block(cid: c, rawData: d)`) and Go receives a struct that returns those values.
- A `chan<- T` channel passed in an option (`options.Unixfs.Events`) becomes a `StreamSink<T>` (`options.unixfs.events(controller.sink)`); the real item type of a `chan<- any` comes from the generator's `chanElem` table (`AddEvent`). Like `ipfs add`, the channel is closed when the call returns: every event arrives and the sink closes before the `Future` completes.
- A package variable becomes a getter; a named function type (`libp2p.RoutingOption`) is an opaque handle, created only in Go; an unnamed func identical to a named type of the package, or of one it imports, uses the named type (`bsfetcher.DefaultPrototypeChooser`).
- A function parameter that returns nothing, `bool` or `error` (a callback) becomes a Dart function (`idx.forEach((mh, offset) {...})`): Go calls a real callback, which takes the arguments to Dart in batches and waits for the verdict; `false` or an exception stops Go, and the call throws the original Dart exception. `batchSize` (optional): invocations per batch, default 1024 (up to 128 KiB, measured) or 1 when the callback receives Go objects; Go stays at most `batchSize - 1` ahead. The call's objects are in use (`isBusy`, `P2pService.busy`); a call to them from inside the callback that waits on a lock the Go function holds becomes `GolangDeadlockException` (WIRE.md, "Callback").
- A function Go keeps past the call (a handler; table `retainedFuncs`: `host.setStreamHandler`) is a retained callback (WIRE.md): Go calls it, on the Dart event loop, for as long as it holds it, and Dart drops it when Go's garbage collector frees it. A root that is an interface type (`network.Notifiee`, `mdns.Notifee`) becomes a factory with one optional function per method (`Notifee(handlePeerFound: (pi) {...})`), each a retained callback. An exception in a retained callback goes to the zone (like a `Timer`'s).
- Functional options built in another package come with it: libp2p's (`libp2p.listenAddrStrings(...)`) build a `config.Option` (`libp2p.Option` is its alias), and a package variable of the option's type is a getter (`libp2p.noListenAddrs`). The type of an internal package seen through an exported alias of the same name lives in the alias's library (`dht.Option`).
- An `any` parameter that takes one Go type (table `anyAs`: `pubsub.registerTopicValidator`'s `val` is a `ValidatorEx`) crosses as that type; a retained callback may return a basic value (`pubsub.validationAccept`), and `cbOnThrow` says what Go gets when the Dart function throws (`validationReject`).
- Tokens (`go/gen/tokens.go`, WIRE.md tag 9): a listed struct type has `static const $type`, which Go turns into `new(T)` where a parameter takes the type by example (`bus.subscribe(event.EvtPeerConnectednessChanged.$type)`, or a list of them), and its values come out of a dynamic value as the class (`sub.out()`); a listed Go function is a `<name>Func` constant that Go gets as the function itself (`libp2p.transport(tcp.newTcpTransportFunc)`).
- An option constructor takes what a function takes: a struct (`pubsub.withGossipSubParams(pubsub.defaultGossipSubParams()..d = 8)`), and a function it keeps becomes a retained callback (`pubsub.withMessageFilter((m) => ...)`, `dht.onRequestHook`); an option inside an option stays one (`namesys.ResolveOption`).
- A trailing variadic whose type does not cross is left out: Go gets none (`event.Bus.Subscribe`'s `opts`), noted under the package.
- `time.Duration` is a Dart `Duration` (nanoseconds on the wire, rounded to microseconds in Dart).
- Errors that wrap `io.EOF`, `io.ErrUnexpectedEOF`, `context.Canceled`, `context.DeadlineExceeded` or IPLD's not found become `GolangEofException`, `GolangUnexpectedEofException`, `GolangCanceledException`, `GolangDeadlineExceededException` and `GolangNotFoundException` (subclasses of `GolangException`), as Go's `errors.Is` would find them.
- A root that is only a struct type (`bsadapter.Adapter`, `basicnode.Prototype__Any`) becomes an empty constructor (`Adapter()`, Go's `new(T)`), and its fields, getters and setters.
- An interface that embeds another gets the cast from it (`idx.asIterableIndex()`, Go's `x.(index.IterableIndex)`).
- A pointer to a basic type (`DagByteRange.To *int64`) becomes `int?`: null is nil.
- A function that returns an unexported type is seen in Dart through an exported interface (table `resultAs`: `merkledag.NewDAGService` → `format.DAGService`); on the wire it is the object's handle.
- A type defined from an interface of another package (`type BaseBlocks blockstore.Blockstore`) gets no methods of its own: list them as roots on the type itself (`node.BaseBlocks.Has`).
- The same Go object always has the same handle, wherever it comes from (a cast, a field read again).
- Methods and functions with a `context.Context` are asynchronous (`Future`); channels become `Stream`; `(T, error)` becomes `T` with `GolangException`.
- Variadics become an optional `List`; functional options mirror the package variables (`options.unixfs.pin(true, '')`).
- A synchronous `NewX` that returns the handle `X` of the same package becomes `factory X(...)` (not for a DTO: `car.newHeader` is a function).
- An `io.Writer` parameter is a `GoHandle?`: a Go object that implements it (`os.File`, `bytes.Buffer`); null = `io.Discard`.
- `fsrepo.Open`: the host cleans the path (`repoPath`, the form `Repo.Path()` returns) before opening, so the config commands, which reopen the repo by `Path()`, reuse the open repo (`fsrepo` keys the open one by the raw string).
- `uint64` integers travel as the same 64 bits in a Dart `int` (like `Uint64List`): from 2^63 up they read as negative; `BigInt.from(v).toUnsigned(64)` reads them unsigned (each field's doc warns).
- An I/O interface parameter (`io.Reader`, `io.ReaderAt`, `io.ReadSeeker`, `car.SectionReader`...) accepts a `Uint8List` (when a `bytes.Reader` implements it) or a handle that implements it (kubo's `files.File`, `os.open`).
- Value types (CID, path, peer ID, multiaddr) keep the string; validation happens in Go, when they cross.
- `config.Config` keeps kubo's JSON (the same as the repo's `config` file) in `json`.
- A Go `nil` result where Dart expects an object becomes `GolangException`.
- Kubo runs in `p2p_host`, in another process (`P2pService.start()` before the API; protocol in `WIRE.md`): a Go panic stops only the service, and pending calls fail with `P2pServiceException`.
- Handles are freed by the Dart `Finalizer` (in batches, through the service's Free function) and are only valid in the service they were born in; Go resources (node, repo) still need Go's own `Close`.
